Here are the agents in order:

1. The unknown developer who tests the tool gives his opinion.

2. The tester: he knows everything about the code and writes a complete bug report

3. The corrector: they correct the code according to what the tester wrote in their bug report

4. The compiler: it compiles the project and the code

5. The executor: it executes the code

6. The tester tests again and confirms or rejects whether everything is correct.

7. The unknown developer returns to test the new version and gives their opinion compared to the previous one.
