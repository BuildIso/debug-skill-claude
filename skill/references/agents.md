Here are the agents in order:

1. The unknown developer who tests the tool gives his opinion.

2. The tester: He knows everything about the code and tests all its functions

3. The writer: he knows everything about the code and writes a complete bug report

4. The coder: he writes the code and corrects the code.

5. The compiler: it compiles the project and the code

6. The executor: it executes the code

7. The tester tests again and confirms or rejects whether everything is correct.

8. The unknown developer returns to test the new version and gives their opinion compared to the previous one.
